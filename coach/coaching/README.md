# Coaching Knowledge Base

Decision-support documents that ground Coach Claude's calls in the actual training-science literature. These are **rules and thresholds**, not textbook chapters — the point is consistent, traceable, auditable coaching decisions, not an encyclopedia.

Every citation in these docs was verified against primary sources (PubMed / journal / consensus-body records) — not recalled from memory. Where a principle is a coaching heuristic rather than settled science, it says so explicitly. That honesty is the point: a good coach knows which rules are laws and which are conventions.

## How these relate to the rest of the system

- **CLAUDE.md** is the operating manual (voice, workflows, hard rules). These docs are the *evidence base* behind the coaching judgments those workflows make.
- **athlete/profile.md** holds the athlete's current numbers (zones, FTP, CSS). `readiness-rules.md` holds their recovery baselines. When fitness shifts, update both.
- **playbooks/** hold discipline-specific session menus (triathlon, running, cycling). These coaching docs hold the cross-discipline evidence base that applies regardless of sport.

## Maintenance

- Recalibrate `readiness-rules.md` baselines every ~4 weeks as fitness shifts.
- If a new coaching question keeps recurring, add a decision rule here rather than re-deriving it each time.
- Keep the honesty: if the evidence for a claim is weak, label it. Don't let a heuristic drift into being quoted as settled science.
- These are general-endurance docs. Discipline-specific content (CSS for swimmers, FTP for cyclists, the open-water pace rule) is additive — an athlete who doesn't do that discipline simply skips it.
